Python พื้นฐาน

ตัวแปร, ชนิดข้อมูล, list/dict, if, for และฟังก์ชัน — พื้นฐานที่ต้องใช้ทุกข้อ

📝 มีแบบฝึกหัดท้ายบท 1 ชุด

Python เป็นภาษาโปรแกรมแบบ interpret (รันทีละบรรทัด) ไม่ต้อง compile — ตัวแปรไม่ต้องประกาศชนิด เพราะเป็น dynamic typing เช่น `name = "สมชาย"` แล้วเปลี่ยนเป็น `age = 20` ได้เลย
Indent (การย่อหน้า) สำคัญมาก — โค้ดที่อยู่ใน if/for/def ต้องย่อหน้าเท่ากัน (ปกติ 4 ช่องว่าง) ถ้าย่อหน้าก็คืออยู่นอกบล็อก

ชนิดข้อมูลที่ต้องจำ

ชนิดตัวอย่างหมายเหตุ
int10, -3, 0จำนวนเต็ม
float3.14, 0.5ทศนิยม
str"สวัสดี", 'A'ข้อความ ต้องมี quote
boolTrue, Falseพิมพ์ใหญ่ตัวแรก (ไม่ใช่ true)
list[10, 20, 30]ลำดับ เปลี่ยนได้ (mutable)
dict{"ชื่อ": "สมชาย"}คู่ key: value

list (ลิสต์)

  • `x = [10, 20, 30]` → index เริ่มที่ 0 → `x[0]` คือ 10
  • `x[-1]` คือ ตัวสุดท้าย (30) — index ติดลบนับจากท้าย
  • `x.append(40)` → เพิ่มท้าย → `[10, 20, 30, 40]`
  • `len(x)` → จำนวนสมาชิก (3)
  • slice: `x[1:3]` → [20, 30] (ตัดจาก index 1 ถึงก่อน index 3)

dict (ดิกชันนารี)

  • `d = {"ชื่อ": "สมชาย", "คะแนน": 85}`
  • เข้าถึงด้วยคีย์: `d["คะแนน"]` → 85
  • เพิ่ม/แก้: `d["เกรด"] = "A"`
  • ลูป dict: `for k in d:` ได้คีย์, `for k, v in d.items():` ได้คีย์+ค่า

if / for / while

age = 20
if age >= 18:
    print("ผู้ใหญ่")
elif age >= 13:
    print("วัยรุ่น")
else:
    print("เด็ก")

for i in range(5):      # 0,1,2,3,4
    print(i)

total = 0
n = 0
while n < 5:
    total += n
    n += 1

ฟังก์ชัน (def)

def add(a, b):
    return a + b

print(add(2, 3))    # 5

# รับค่าจากคีย์บอร์ด — input() คืนค่าเป็น str เสมอ
name = input("ชื่อ: ")
age = int(input("อายุ: "))   # ต้องแปลงเป็น int ก่อนนับเลข
กับดักที่เจอบ่อยในข้อสอบ`input()` คืนค่าเป็น string เสมอ — ถ้าใส่ `input()` เข้าไปคำนวณ เช่น `age + 1` จะ error ต้อง `int(input(...))` ก่อน และการรวม string กับ number ต้องแปลง `str(age)` เช่น `"อายุ " + str(age)`

print() เบื้องต้น

x = 10
print("ค่า =", x)        # ค่า = 10 (เว้นวรรคให้เอง)
print(f"ค่า = {x}")     # f-string: แทรกตัวแปรด้วย {}
print("บรรทัด1\nบรรทัด2")  # \n = ขึ้นบรรทัดใหม่

Anaconda · Jupyter · Spyder

เครื่องมือทำงานของนัก Data Science — ต้องรู้ว่าแต่ละตัวใช้ทำอะไร

📝 มีแบบฝึกหัดท้ายบท 1 ชุด

Anaconda คือชุดแจกจ่าย (distribution) ที่รวม Python + เครื่องมือ Data Science + ไลบรารีหลัก มาให้พร้อม (matplotlib, numpy, opencv, tensorflow ฯลฯ) — ติดตั้งครั้งเดียวได้ทุกอย่าง ไม่ต้องลงทีละตัว
conda เป็นตัวจัดการแพ็กเกจและสภาพแวดล้อม (environment) ที่มาพร้อม Anaconda

คำสั่ง conda ที่ต้องจำ

Jupyter Notebook

  • เป็นโน้ตบุ๊กแบบ cell — รันโค้ดทีละกล่อง (cell) แล้วเห็นผลลัพธ์ข้างใต้

  • cell มี 2 แบบ: Code (เขียนโค้ด) และ Markdown (เขียนข้อความ/อธิบาย)
  • ตัวแปรที่รันใน cell ก่อนหน้าจะจำไว้ใช้ต่อได้ (ต้องรันตามลำดับ)

  • ไฟล์มีนามสกุล `.ipynb`

matplotlib

วาดกราฟเส้น/แท่ง/กระจาย/ฮิสโทแกรม ใส่ป้ายกำกับและบันทึกรูป

📝 มีแบบฝึกหัดท้ายบท 1 ชุด

matplotlib เป็นไลบรารีวาดกราฟยอดนิยม — เรียกใช้ด้วยคำย่อ `plt` แล้ววาดได้หลายแบบ หลัก ๆ คือสร้าง figure แล้วเรียกฟังก์ชันวาดทีละอัน สุดท้าย `plt.show()`

โครงสร้างพื้นฐาน

import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [10, 20, 15, 30]

plt.plot(x, y, marker="o")      # เส้นเชื่อมจุด
plt.xlabel("ปี")
plt.ylabel("ยอดขาย")
plt.title("ยอดขายรายปี")
plt.grid(True)                  # ตารางกริด
plt.show()                      # แสดงกราฟ

# บันทึกรูปแทนการ show
plt.savefig("graph.png", dpi=300)

ชนิดกราฟที่ต้องรู้

ฟังก์ชันใช้ทำอะไรตัวอย่าง
plt.plot(x, y)กราฟเส้น (trend)ยอดขายตามปี
plt.scatter(x, y)กราฟจุดกระจายความสัมพันธ์ 2 ตัวแปร
plt.bar(x, y)กราฟแท่งเปรียบเทียบหมวดหมู่
plt.hist(data)ฮิสโทแกรม (ความถี่)การกระจายของข้อมูล

กราฟหลายชุด + legend

import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
sale = [10, 20, 15, 30]
cost = [5, 8, 10, 12]

plt.plot(x, sale, label="ยอดขาย")
plt.plot(x, cost, label="ต้นทุน")
plt.legend()                # แสดงกล่องคำอธิบาย
plt.xlabel("เดือน")
plt.ylabel("หมื่นบาท")
plt.title("ยอดขาย vs ต้นทุน")
plt.show()

figure และ subplot

  • `plt.figure(figsize=(8, 5))` — ตั้งขนาดกราฟเป็นนิ้ว
  • `fig, ax = plt.subplots(1, 2)` — วาด 2 กราฟในแถวเดียวกัน (1 แถว 2 คอลัมน์)
  • เมื่อใช้ ax ให้วาดด้วย `ax.plot(...)`, `ax.set_title(...)` แทน plt
  • `plt.style.use("ggplot")` — เปลี่ยนธีมสีกราฟ
show() vs savefig()ถ้าเรียก `plt.show()` ก่อน `plt.savefig()` รูปที่บันทึกจะว่างเปล่า — ใช้อย่างใดอย่างหนึ่ง หรือ savefig ก่อน show

OpenCV · Image Processing

อ่าน แสดง แปลงภาพเป็นขาวดำ ปรับขนาด ละลายขอบ ตรวจจับขอบ — ต้นทางก่อนเข้าโมเดล AI

📝 มีแบบฝึกหัดท้ายบท 1 ชุด

OpenCV (cv2) เป็นไลบรารีประมวลผลภาพยอดนิยม — ข้อสอบมักให้อ่านภาพแล้วแปลงเป็นขาวดำ, ย่อขนาด, เบลอ หรือหาเส้นขอบ ก่อนนำเข้าโมเดล

อ่าน / แสดง / บันทึกภาพ

import cv2

img = cv2.imread("cat.jpg")          # อ่านภาพ → อาร์เรย์ numpy
cv2.imshow("window", img)             # เปิดหน้าต่างแสดงภาพ
cv2.waitKey(0)                        # รอจนกว่าจะกดปุ่มใดปุ่มหนึ่ง
cv2.destroyAllWindows()               # ปิดหน้าต่าง

cv2.imwrite("out.jpg", img)           # บันทึกภาพ
อาร์เรย์ภาพใน OpenCVภาพสีที่ `cv2.imread` อ่านมาเรียงช่องเป็น BGR (Blue-Green-Red) ไม่ใช่ RGB — ต้องใช้ `cv2.cvtColor` ตอนแปลง ภาพขาวดำมี 1 ช่อง ภาพสีมี 3 ช่อง

การแปลงที่เจอบ่อย

import cv2

img = cv2.imread("dog.jpg")

# ขาวดำ
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# ปรับขนาด (กว้าง, สูง)
resized = cv2.resize(img, (150, 150))

# ละลายขอบ / ลดสัญญาณรบกวน
blur = cv2.GaussianBlur(img, (5, 5), 0)

# ตรวจจับขอบ (Canny)
edges = cv2.Canny(img, 50, 150)

# ท้ายเป็น 0-255 → ค่า 127 เป็นจุดแบ่ง ขาว/ดำ
_, thresh = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

สรุปฟังก์ชันที่ต้องจำ

ฟังก์ชันหน้าที่
cv2.imread(path)อ่านภาพเป็น numpy array (BGR)
cv2.imshow(name, img) + waitKey(0)แสดงภาพในหน้าต่าง
cv2.imwrite(path, img)บันทึกภาพ
cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)แปลงเป็นขาวดำ
cv2.resize(img, (w, h))ปรับขนาด (สังเกตลำดับ กว้าง, สูง)
cv2.GaussianBlur(img, (5,5), 0)เบลอ ลด noise
cv2.Canny(img, 50, 150)หาเส้นขอบ
cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)แบ่งขาว-ดำด้วยค่า threshold
ทำไมต้อง preprocessโมเดลหมา/แมวต้องการภาพขนาดคงที่ (เช่น 150×150) และค่าพิกเซล 0–1 — resize ให้เท่ากัน + หาร 255 (normalize) ก่อนเข้าโมเดล ถ้าไม่ทำโมเดลเรียนรู้ยากและขนาดภาพบังคับไม่ได้

TensorFlow + Keras · หมา vs แมว

โครงข่ายประสาทเทียม CNN แยกหมากับแมว — ตั้งแต่โหลดข้อมูลจนถึงทำนาย

📝 มีแบบฝึกหัดท้ายบท 1 ชุด

TensorFlow เป็นไลบรารี Machine Learning ของ Google และ Keras เป็น API ระดับสูงที่อยู่ใน TensorFlow (`tf.keras`) ช่วยให้สร้างโมเดลได้ง่าย งานสุดคลาสสิกคือ จำแนกภาพหมากับแมว (binary classification) ด้วยโครงข่าย CNN

เตรียมข้อมูล (ImageDataGenerator)

from tensorflow.keras.preprocessing.image import ImageDataGenerator

train_datagen = ImageDataGenerator(rescale=1./255)

train_ds = train_datagen.flow_from_directory(
    "data/train",          # มีโฟลเดอร์ย่อย cat/ และ dog/
    target_size=(150, 150), # ปรับขนาดภาพ
    batch_size=32,
    class_mode="binary",   # แยก 2 กลุ่ม → ค่า 0/1
)

val_ds = val_datagen.flow_from_directory("data/validation", target_size=(150, 150), batch_size=32, class_mode="binary")
rescale = 1./255พิกเซลภาพมีค่า 0–255 → หารด้วย 255 ให้เหลือ 0–1 (normalize) เพื่อให้โมเดลเรียนรู้เร็วและแม่นขึ้น — จำไว้ขึ้นใจ

สร้างโมเดล CNN

from tensorflow import keras
from tensorflow.keras import layers

model = keras.Sequential([
    layers.Conv2D(32, (3, 3), activation="relu", input_shape=(150, 150, 3)),
    layers.MaxPooling2D(2, 2),
    layers.Conv2D(64, (3, 3), activation="relu"),
    layers.MaxPooling2D(2, 2),
    layers.Flatten(),
    layers.Dense(128, activation="relu"),
    layers.Dense(1, activation="sigmoid"),   # ชั้นสุดท้าย 1 ค่า 0-1
])

model.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])
model.fit(train_ds, epochs=10, validation_data=val_ds)

ชั้น (Layer) ที่ต้องจำ

ชั้นหน้าที่
Conv2Dสกัดคุณลักษณะ (feature) จากภาพ เช่น เส้น, ขอบ, หู, ตา
MaxPooling2Dย่อขนาดภาพลง ลดจำนวนพารามิเตอร์ (เลือกค่ามากสุดในบริเวณ)
Flattenทำให้ข้อมูล 2 มิติ กลายเป็น 1 มิติ (เส้นตรง) ก่อนเข้า Dense
Denseชั้นประสาทเต็มเชื่อมต่อทุกจุด (fully connected)

ชั้นสุดท้าย: sigmoid vs softmax

  • แยก 2 กลุ่ม (หมา/แมว) → ใช้ `Dense(1, activation="sigmoid")` + `loss="binary_crossentropy"`
  • แยก หลายกลุ่ม (เช่น หมา/แมว/นก) → ใช้ `Dense(3, activation="softmax")` + `loss="categorical_crossentropy"`
  • sigmoid คืนค่า 0–1 (ความน่าจะเป็น) — ถ้าผล < 0.5 = กลุ่มแรก, ≥ 0.5 = กลุ่มสอง

ทำนายผล

import cv2

img = cv2.imread("test.jpg")
img = cv2.resize(img, (150, 150))
img = img.reshape(1, 150, 150, 3)   # เพิ่มมิติ batch (1 ภาพ)
img = img / 255.0                    # normalize

pred = model.predict(img)            # เช่น [[0.87]]
if pred[0][0] >= 0.5:
    print("หมา")
else:
    print("แมว")
ตัวเลขที่ต้องเดาได้`epochs=10` = วนเทรนทั้งชุด 10 รอบ · `batch_size=32` = เลือกทีละ 32 ภาพ · `model.fit` ใช้ข้อมูล train · `validation_data` ตรวจผลเทรน · `metrics=["accuracy"]` วัดความแม่นยำ
